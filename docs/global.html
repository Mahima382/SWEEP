SQLite connection (Model-layer database access). Uses Node's built-in node:sqlite module (DatabaseSync) — no external driver dependency, no native build step. The schema is (re)applied on every boot via "CREATE TABLE IF NOT EXISTS", so first run and later runs both work unattended. DB_PATH (optional): file path for the database file. Registers a new account for one of the four self-service roles (household, collector, global, company) — FR-01. Only the minimal credential fields are collected here (full name, email, mobile, password); role-specific KYC/profile fields are gathered later in the post-login profile completion flow (see PROFILE_COMPLETION_SPEC.md).
